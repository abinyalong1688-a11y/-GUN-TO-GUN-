# 角色足部穿模校验 · 测试报告（v1.11.0）

**测试项**：干员足部网格 / 骨骼与地面几何体的穿模校验
**判定标准**：足部模型不侵入地面模型下方，无明显穿模；允许设计预期内的微小贴合。
**结论**：**通过（PASS）**——发现并修复 1 个真实穿模缺陷（F-1）；修复后 4 张地图 × 300 个动画采样点中，足部最大侵入深度 **0.000 m**。

---

## 1. 测试环境与方法

- 构建：`dist/gun-to-gun.html` v1.11.0，单文件 3.16 MB。
- 角色：默认 GLB 骨骼模型（脚趾/脚掌骨骼），以及 `?model=proc` 程序化模型回退。
- 地图：`desert` / `snow` / `snowtown` / `ember`。
- 方法：不测碰撞胶囊，直接测**渲染网格**：
  1. GLB：遍历 `SkinnedMesh`，取蒙皮权重主要绑定到 `L_Foot / L_ToeBase / R_Foot / R_ToeBase` 的 145 个顶点，用 `getVertexPosition()` 计算当前蒙皮变形并转换到世界坐标。
  2. 程序化：遍历 `legL / legR` 下的靴子/鞋底刚性网格顶点。
  3. 对每个顶点比较其世界 Y 与脚下表面高度；`surfaceY - vertexY > 0` 记为侵入。
- 动画驱动：不依赖 rAF，直接设置 `walkT / moveK / yaw` 并调用 `_animate()`，保证待机、走、跑、转向的相位可复现；平台用例把角色放到实际碰撞体顶面。
- 相机：透视近距离、低机位、长焦（近正交）侧视、多角度环视；截图用于目视复核。

## 3. 缺陷 F-1（已修复）：可行走区地面高于碰撞平面

**现象**：角色站在出生点附近时，靴子/脚踝陷入沙地，最深约 **35 cm**；在其他区域又会悬浮约 **23 cm**。碰撞胶囊、射击命中、移动都正常，属于典型的“碰撞正常但美术模型穿插”。

**根因**：`world.js` 给 360×360 地面网格做了 ±0.5 m 的噪声起伏，但玩家/机器人移动、出生点、掩体顶面全部以 `y=0` 为地面。两者在 r≤56 的可玩区内不一致。

**修复**：
- 新增 `src/terrain.js`：`terrainHeight(x,z)` 作为渲染地面的唯一高度来源；`r ≤ 58` 精确为 0（覆盖 r=56 玩家边界并多留一圈网格），58–72 平滑过渡，之后恢复沙丘。
- `world.js` 的地面顶点改用该函数；远山/沙丘保留在可玩区外。
- 新增 `src/footAudit.js`：按渲染顶点审计足部侵入；接入 `?e2e=1` 回归。
- 新增单元测试 `tests/terrain.test.mjs`：可玩区密集网格 + 边界环必须为 0，过渡连续，远山仍存在。

**修复前后实测**：

| 指标 | 修复前 | 修复后 |
|---|---|---|
| 出生点地面高度（渲染） | +0.187 ~ +0.355 m | 0.000 m |
| 角色脚底与地面 | 陷入 18.7 ~ 35.5 cm | 最大侵入 0.000 m |
| 低洼处 | 悬浮 23.1 cm | 0.000 m |
| r≤56 地面网格顶点 Y 范围 | 约 ±0.5 m | min = max = 0 |

## 4. 观察项（不构成本测试项的失败）

1. **行走时足部离地，最大约 12.5 cm**：当前步态是“双腿摆动 + 身体上浮 3.5 cm”，没有脚掌锁定/髋部下沉。脚始终在地面**上方**，不满足“侵入地面”的缺陷判定；但近距离看会有轻微漂浮感。若后续要求严格贴地，需要增加 Foot IK（脚掌锁定 + 髋部按支撑腿下沉），属于独立的动画改进。
2. **脚踝只补偿膝盖，不补偿髋部摆动**：`_animate()` 中 `poseRot(foot, -knee*0.55)` 让鞋底在屈膝时保持接近水平；髋部摆动时鞋底会随腿倾斜。当前摆幅下仍未低于地面（实测 0 侵入），但这也解释了观察项 1 的离地。
3. **死亡倒地**：尸体会侧倒/俯卧贴地，可能产生身体与地面的艺术重叠；本测试项只覆盖待机/走/跑/转向/落地，死亡姿态未纳入判定。
4. **斜坡/台阶行走**：游戏没有可行走斜坡，机器人也不能走上箱顶；若未来加入斜坡或楼梯，需要先补 Foot IK，否则刚性鞋底会在上坡侧/台阶边缘穿插。

## 6. 判定

- **穿模（侵入地面下方）**：**PASS**。修复后所有可玩区域、所有采样相位、平台顶面均为 0 侵入。
- **F-1**：已修复并加入回归，防止地面再次起伏到脚底以下。
- **Foot IK / 根运动**：已核查；当前实现无 Foot IK、无根运动。足部离地属于“未贴合”而非“穿模”，单独记录为后续动画改进项。
