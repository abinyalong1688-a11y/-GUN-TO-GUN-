# GUN TO GUN

单文件 3D FPS 网页游戏 —— CS 风格阵营对战 · 四张地图 · 7 种真实武器 · 真实物理(重力/跳跃/蹲伏/后坐力弹道) · CT/T 男女角色 · 3v3 人机乱斗 · 无尽波次。
按《从一句需求到一个能双击打开的 3D FPS》教程的验收标准实现并扩展。

## 玩

**双击打开 [`dist/gun-to-gun.html`](dist/gun-to-gun.html) 即可游玩**(约 0.65 MB,零外部请求,断网可玩)。

| 键位 | 功能 |
|---|---|
| W A S D | 移动(Shift 冲刺) |
| 空格 | 跳跃(重力/落地物理,可跳上木箱、箱堆搭人梯上集装箱) |
| Ctrl | 蹲伏(降身位、减速、散布收紧) |
| 鼠标 | 瞄准(左键射击)· 360° 自由视野(俯仰可全程翻转) |
| 右键 | 机瞄(ADS)· AUG/AWP/SG 553 高倍开镜(镜筒遮罩+变焦补偿灵敏度)· 军刀右键重刺 |
| R | 换弹 |
| 1 / 2 / 3 | 切换武器:**反复按 1 循环 4 把主武器** / 沙漠之鹰 / 军刀(滚轮顺序切换全部 6 把) |
| TAB | 计分板(乱斗模式) |
| ESC | 暂停 |

> **界面语言**:中国 IP 自动中文界面,海外 IP 自动全英文界面(同步首帧判定 + 异步 IP 探测双端点兜底,离线/探测失败回落中文);测试可用 `?ipcc=US` / `?ipcc=CN` 强制。

## 技术架构(与教程分层一致)

```
src/
  assets.js   材质层 —— 1024 Canvas 程序化 PBR 贴图(沙/雪/玄武岩)+ 法线图 + CS 枪木/阵营布料 + AbinStudio 广告贴图,零图片文件
  world.js    场景层 —— 参数化天空 shader(日落/月夜星空/雪镇白昼/熔岩) + 四张地图 + 光照/雾/氛围粒子
  weapon.js   武器层 —— CS 体系三槽位(AK-47/M4A4·沙鹰·军刀) viewmodel + 第一人称手臂(战术手套) + 半自动扳机 + 挥砍动画 + 后坐/ADS/换弹/抛壳
  heroes.js   角色层 —— 3D 真人风阵营角色(女模特级 CT / 帅气男性 T:Lathe 躯干曲面·五官·发型物理·阵营着装)与 3v3 AI
  enemies.js  敌人层 —— 三类无人机(精化造型:传感窗/护环/细节件)+ AI + 弹丸 + 遮挡检测
  player.js   玩家层 —— 移动/圆形-AABB 碰撞/生命/回血
  waves.js    玩法层 —— 波次调度/出怪节流/补给
  effects.js  特效层 —— GPU 点粒子 + 双层曳光弹(白热弹芯/弹色光晕/弹头亮光,按武器颜色弹速参数化) + 命中闪光 + 弹孔贴花(贴合法线) + 火球/冲击环/碎片
  audio.js    音频层 —— WebAudio 实时合成全部音效(含沙鹰重磅枪声/军刀挥砍),零音频文件
  ui.js       UI 层 —— 登录菜单/四态界面/击杀播报/计分板(CT vs T)/武器栏
  main.js     主循环 —— 状态机 + 射线命中(静态/无人机/角色球体) + 军刀近战判定 + Bloom/ACES
build.mjs     esbuild 打包为单文件 HTML
```

## 构建 / 测试

```bash
npm install        # three@0.170.0 + esbuild
npm run build      # 产出 dist/gun-to-gun.html
npm test           # 单元测试(node --test):工具/武器数值/移动物理/波次调度 20 项
npm run serve      # 本地服务器 http://127.0.0.1:8137/(仅测试用)
```

自动化验证钩子:

- `?shot=menu|combat|dm|over` —— 直接进入对应状态供截图验收
- `?selftest=1` —— 武器自测(主武器命中击杀 + 沙鹰半自动 + 军刀近战),结果写入调试条与 console
- `?e2e=1` —— **系统集成测试**:12 项端到端断言(装载/开镜/后坐力弹道/重力跳跃/箱顶着陆/蹲伏/负重移速/**4 主武器同槽循环**/暴击/XSS 防护/360° 视野),结果写入 `window.__e2e` 与调试条;确定性驱动,后台标签页可复现
- `?perf=1` —— 卡顿监控:慢帧(>25ms)计数与最大帧耗时定期输出 console
- `?ipcc=US` / `?ipcc=CN` —— 强制界面语言(默认按 IP 自动:海外英文 / 中国中文;探测失败静默回落)

## 云端部署与离线模式

游戏挂云端托管时,**将 `dist/` 三件套整体上传**:`gun-to-gun.html` + `sw.js` + `manifest.webmanifest`。

- **离线模式(PWA)**:内置 Service Worker —— 访客首次联网打开即缓存游戏本体,之后**断网也能从缓存重新打开**(导航网络优先保证更新,断网回落缓存);同时支持浏览器"安装到桌面"全屏运行
- **语言探测**:云端版通过客户端 IP 自动判定界面语言(海外英文/中国中文),该请求为可选外部调用 —— 断网或失败时静默回落,不影响游戏本体(本体依旧零外部请求)
- 跨域探测请求不会被缓存;游戏版本更新后 SW 缓存按版本号自动清理

按可投产标准完成的安全 / 稳定性 / 性能自检:

| 类别 | 加固项 |
|---|---|
| 安全 | 玩家昵称等用户可控字符串进入 killfeed / 计分板 / 结算页 innerHTML 前全部 HTML 转义(防存储型 XSS) |

| 稳定 | `localStorage` 全部经安全封装(隐私模式 / 禁用存储不崩溃,读写均有兜底) |
| 稳定 | 持久化数值脏数据兜底:灵敏度/音量/画质/角色/地图/模式/主武器/最佳分,非法值自动回落默认 |
| 稳定 | WebGL 上下文丢失(驱动崩溃/切显卡/休眠)→ 可见提示 + 自动恢复重载 |
| 稳定 | 主循环异常熔断:单帧异常不再静默终止 rAF 链,熔断停机并在调试条输出堆栈 |
| 性能 | 射击热路径零分配:`fire()` 全程复用向量池,射线-球判定复用模块级向量,计分浮字复用临时向量 |
| 性能 | 无人机 AI 热路径向量池化 + **几何体按类型缓存共享**(消除出怪分配尖峰与几何体泄漏) |
| 性能 | HUD 热路径 DOM 写入去重(弹药/准星未变化不写) |
| 性能 | 切图资源完整释放:几何体(含 Points 氛围粒子)+ 本图新建材质(天空 shader/灯泡/信标/熔岩裂纹/冷却塔) |
| 性能 | 卡顿监控计数器(`?perf=1`):慢帧(>25ms)比例与最大帧耗时 |
| 规范 | 清理死代码;版本号写入菜单页脚与 console 横幅;`npm test` 单元测试 20 项 + `?e2e=1` 集成测试 11 项 |
